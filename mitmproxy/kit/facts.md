# Facts about this repository

## Building and testing
AGENTS.md: "Always use `uv run pytest` and don't run pytest directly."
- Whole suite: `uv run tox` · Python only: `uv run tox -e py`
- One file: `uv run pytest test/mitmproxy/addons/test_anticache.py`
- One test: `uv run pytest test/mitmproxy/addons/test_anticache.py::TestAntiCache::test_simple`
- `uv run tox -e lint` (ruff) · `-e fix` · `-e mypy`; after adding a source file, `-e individual_coverage -- FILENAME`
- Frontend: `cd web && npm ci && npm test`
- Tests mirror the package: `mitmproxy/<d>/<n>.py` -> `test/mitmproxy/<d>/test_<n>.py`. `test_` is glued to the literal basename, so `_view_zip.py` -> `test__view_zip.py`.

## Where things live
- mitmproxy/ — the only installable package: addons/ features, proxy/ sans-io core, net/ wire codecs, tools/ the CLI entry points
- test/ — the suite + two CI gates that are not tests: filename_matching.py, individual_coverage.py
- web/ — mitmweb TS/React frontend; web/gen/ = the code generators
- docs/ — Hugo site; docs/build.py runs every docs/scripts/*.py

## Changing things together
- New addon: `mitmproxy/addons/__init__.py` needs BOTH an import line and a `default_addons()` entry — no auto-discovery.
- New `Hook` subclass: also list it in `docs/scripts/api-events.py`, or the docs CI job raises `RuntimeError("Not documented: ...")`.
- New proxy mode: a `ProxyMode` in `proxy/mode_specs.py` AND a paired `ServerInstance[...]` in `proxy/mode_servers.py`, else `make()` KeyErrors.
- Bumping `FLOW_FORMAT_VERSION` (`version.py`): add a converter + its `converters` entry in `io/compat.py`, else `migrate_flow` raises.

## Traps
- A new `mitmproxy/**/*.py` needs its mirrored test file, and that file ALONE must reach 100% coverage of it or the path goes in `[tool.pytest.individual_coverage].exclude`; exemptions live in `test/filename_matching.py`.
- `asyncio.create_task` is banned in `mitmproxy/` (ruff TID251): use `mitmproxy.utils.asyncio_utils.create_task` with `name=` and `keep_ref=`.
- ruff isort: `force-single-line`, first-party LAST after local-folder. PEP-8 order fails lint.
- Never hand-edit a file headed "Auto-generated by"; `web/gen/all` rewrites them in CI.
