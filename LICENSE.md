## What this repository is

Five worked examples of a context-engineering engagement, published so that a prospective client
can see what one delivers and what it measured. Each `*/kit/` directory is the complete
deliverable for that codebase, unedited.

## What you may do with it

Read it, run it, and copy it into a checkout of the codebase it was written for — that is what
the case studies invite you to do, and the measurements are worth nothing if you cannot reproduce
them.

The kits themselves are not offered under an open-source licence. They are engagement
deliverables, shown here as examples. Each one is written against one specific codebase: its
value is in the study of that codebase, not in the file format, so copying one into a different
repository gains you nothing a blank file would not.

## The codebases

The five projects studied here are independent open-source works under their own licences —
Keycloak (Apache-2.0), Rocket.Chat (MIT), SuiteCRM (AGPL-3.0), mitmproxy (MIT), jq (MIT). This
repository contains no code from any of them. It contains documentation *about* them: paths,
names, conventions and the occasional shell command. Nothing here is affiliated with or endorsed
by those projects.

## The measurements

Every figure on these pages was produced by the protocol each page describes, and is computed at
build time from the session records rather than typed into a page, so a number and the
measurement behind it cannot drift apart. Where a result did not clear the noise the benchmark
measured on itself, the page says so instead of rounding it up.
